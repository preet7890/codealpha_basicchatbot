# codealpha_basicchatbot
Description:

This is a simple rule-based chatbot created using Python.
The chatbot responds to basic user messages with predefined replies.

Features:

- Responds to greetings like "hello"
- Answers simple questions
- Ends chat when user types "bye"
- Console-based interaction

Technologies Used:

- Python

Concepts Used:

- if-elif statements
- while loop
- functions
- user input/output

How to Run:

1. Install Python or use Pydroid 3.
2. Save the file as "chatbot.py"
3. Run the program.

Example Inputs:

- hello
- how are you
- what is your name
- bye
